# 縦書きドキュメント v001

Google Docsに近い操作感を目指した、ブラウザで動く縦書きエディタのv001です。

## 主な機能

- 縦書き入力（右から左）
- 横書きへの切り替え
- 日本語IME入力
- Undo / Redo
- 太字・斜体・下線
- フォント変更
- 文字サイズ変更
- 見出し1 / 見出し2 / 引用
- 検索・置換
- 文字数表示
- ズーム
- 自動保存（LocalStorage）
- TXT書き出し
- Word互換 `.doc` 書き出し
- HTML書き出し
- 印刷

## 起動方法

### 最も簡単
`index.html` をブラウザで開いてください。

### ローカルサーバー
```bash
python -m http.server 8000
```
その後、`http://localhost:8000` を開きます。

## GitHub / Vercel

静的ファイルのみなので、このフォルダをそのままGitHubへアップロードしてVercelに接続できます。
ビルドコマンドは不要です。

## v001の仕様上の注意

- 保存先はブラウザのLocalStorageです。同じ端末・ブラウザ内で保存されます。
- `.doc` はWord互換HTMLです。真の `.docx` 生成はv002以降で追加可能です。
- ページはA4風の1枚キャンバスとして表示しています。厳密な自動改ページは未実装です。
- Google Docsそのもののコピーではなく、一般的なドキュメントUIの操作感を参考にした独自UIです。
