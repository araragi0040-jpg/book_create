# 縦書きドキュメント v005

Google Docsに近い操作感を目指した、ブラウザで動く縦書きエディタです。

## v005の変更点

- 用紙サイズ名の横に実寸を表示
  - A4（210mm×297mm）
  - A5（148mm×210mm）
  - B5（182mm×257mm）
  - B6（128mm×182mm）
  - Letter（215.9mm×279.4mm）
- 余白設定を追加
  - 上 / 下 / 左 / 右をmm単位で指定
  - 初期値は各18mm
  - 設定内容はPDF / HTML / IDML出力にも反映
- 自動改ページを追加
  - 現在の用紙の入力可能範囲を超えると、同じタブ内に2ページ目以降を自動生成
  - タブの文字数は複数ページ分を合計して表示
  - PDF / HTML / IDMLにも複数ページを反映

## v004までの既存機能

- 緑ベースUI
- 用紙サイズ選択（A4 / A5 / B5 / B6 / Letter）
- 用紙の縦長 / 横長切替
- 縦書き / 横書き切替
- 日本語IME入力
- Undo / Redo
- 太字・斜体・下線
- 見出し・フォント
- 文章内の文字サイズ個別指定
- 文章内の英字方向個別指定
- タブ追加 / タブ名変更 / タブごとの文字数表示
- 検索・置換
- ズーム
- ブラウザ内自動保存
- PDF / HTML / IDML 書き出し
- 印刷

## 起動方法

`index.html` をブラウザで開くだけで動作します。
GitHub Pages / Vercel / Cloudflare Pages等の静的ホスティングにも配置できます。
