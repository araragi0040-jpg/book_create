# 縦書きドキュメント v002

Google Docsに近い操作感を目指した、ブラウザで動く縦書きエディタです。

## v002の追加点

- UIを緑ベースに変更
- 用紙サイズを選択可能
  - A4
  - A5
  - B5
  - B6
  - Letter
- 用紙を「縦長 / 横長」で切り替え可能
- 選択した用紙設定を自動保存
- HTML / Word互換出力にも用紙サイズ・向きを反映
- 印刷時も選択した用紙サイズを反映
- v001のブラウザ保存データがあれば自動移行

## 既存機能

- 縦書き / 横書き切替
- 日本語IME入力
- Undo / Redo
- 太字・斜体・下線
- 見出し・フォント・文字サイズ
- 検索・置換
- 文字数表示
- ズーム
- ブラウザ内自動保存
- TXT / Word互換 (.doc) / HTML 出力
- 印刷

## 起動方法

`index.html` をブラウザで開くだけで動作します。
GitHub Pages / Vercel / Cloudflare Pages等の静的ホスティングにも配置できます。
