# 縦書きドキュメント v004

Google Docsに近い操作感を目指した、ブラウザで動く縦書きエディタです。

## v004の変更点

- 文字サイズを数値入力で変更可能
- タブ機能を追加
  - タブを追加して本文を切り替え可能
  - 各タブに文字数を表示
- 書き出し形式を PDF / HTML / IDML の3種類に変更
  - PDFはブラウザの印刷画面から「PDFに保存」
  - HTMLは縦書き書式付き
  - IDMLはAdobe InDesign向け
- 縦書き時の英字表示を「横向き / 縦向き」で切り替え可能

## 既存機能

- 緑ベースUI
- 用紙サイズ選択（A4 / A5 / B5 / B6 / Letter）
- 用紙の縦長 / 横長切替
- 縦書き / 横書き切替
- 日本語IME入力
- Undo / Redo
- 太字・斜体・下線
- 見出し・フォント
- 検索・置換
- ズーム
- ブラウザ内自動保存
- 印刷

## 起動方法

`index.html` をブラウザで開くだけで動作します。
GitHub Pages / Vercel / Cloudflare Pages等の静的ホスティングにも配置できます。


## v004 changes
- タブ名をダブルクリックして変更可能
- 選択した文章内の英字方向を「英字：横 / 英字：縦」ボタンで個別指定可能
- 選択した文章内の文字サイズを数値入力で個別変更可能
