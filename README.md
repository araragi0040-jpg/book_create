# 縦書きドキュメント v008

v007の外観と既存機能を維持し、長文執筆時の安定性と原稿ファイルの保存・読み込みを追加したバージョンです。

## v008の変更点

1. **日本語IMEのEnter**：漢字変換中の確定Enterを通常の改行処理が奪わないよう、`compositionstart` / `compositionend`、`isComposing`、キーコード229を確認します。
2. **IME変換中の改ページ待機**：文字変換中はページ構成やDOM・文字サイズを変更せず、変換確定後に再レイアウトします。
3. **削除時のページ詰め戻し**：ページをまたぐ文章を再配置し、前のページに空きができたら後ろのページの本文が戻るようにしました。文字数や書式のデータは保持します。
4. **ページ境界での編集**：前後ページの境界で Backspace / Delete と矢印キーによるカーソル移動を補助します。また Ctrl+Enter の手動改ページは、文章の再レイアウト・原稿ファイル再読み込み後も維持します。
5. **ローカル原稿ファイルの保存／読込**：「ファイル」→「原稿ファイルを保存」「原稿ファイルを開く」から、専用 `.tategaki.json` ファイルを保存・読み込みできます。ショートカットは `Ctrl+S` / `Ctrl+O`（macOSではCmd）。
6. ブラウザ内の自動保存は引き続き利用できます。v007以前の保存データも読み込み対象です。

## 原稿ファイルの保存と再開

- **作業を終了するとき**：「ファイル」→「原稿ファイルを保存」から `書籍名.tategaki.json` を保存してください。
- **作業を再開するとき**：v008で「ファイル」→「原稿ファイルを開く」を選び、そのファイルを指定してください。現在の文書と入れ替える前に確認画面が出ます。
- タブの本文、タブ名、縦横書き、英字向き、用紙サイズ・向き、余白、ズームなどをひとまとめで保存します。
- `.tategaki.json` は**再編集用原稿**です。従来のPDF・HTML・IDMLの「書き出し」とは別です。
- 自動保存先はブラウザの `localStorage` です。同じ端末・同じブラウザの同じ公開URLで引き継がれます。環境をまたぐ場合は必ず原稿ファイルを使ってください。

## 維持する機能

- Google Docs風の緑ベースUI、縦書き・横書き
- A4 / A5 / B5 / B6 / Letter、縦長・横長、余白mm設定、余白ガイド
- 複数ページの縦方向表示とページ末端での自動改ページ
- フォント・文字サイズ・文字単位のサイズ／英字縦横の変更、太字・斜体・下線、見出し
- タブ追加、ダブルクリックでタブ名変更、タブごとの文字数
- 検索・置換、ズーム、PDF / HTML / IDML出力、印刷

## 起動方法

同じフォルダの `index.html` を開いてください。GitHub Pages / Vercel / Cloudflare Pagesにもそのまま配置できます。

## 現時点の制約

- 表示ページは独立した編集領域です。**ページをまたいでドラッグして一括範囲選択・書式変更する操作**は、まだGoogle Docsと完全には同等ではありません。ページの境界での削除・移動は補助します。これはより大きな編集エンジンの構造改修が必要な項目です。
- Undo/Redoのページまたぎはまだ改善対象です。
- IDML出力は従来の簡易版であり、フォント・文字書式の完全な引継ぎには未対応です。
- PDFはブラウザの印刷画面で「PDFに保存」を選択します。
